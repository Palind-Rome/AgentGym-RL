## 本仓库工作目标

核心想法：调研并尝试将 OPD/on-policy distillation 适配到 AgentGym-RL 的 multi-turn agent RL 场景中。

如果你是 Codex，关于 OPD 需要调研：

[On-Policy Distillation - Thinking Machines Lab](https://thinkingmachines.ai/blog/on-policy-distillation/) 与 [tinker-cookbook/tinker_cookbook/recipes/distillation/on_policy_distillation.py at main · thinking-machines-lab/tinker-cookbook](https://github.com/thinking-machines-lab/tinker-cookbook/blob/main/tinker_cookbook/recipes/distillation/on_policy_distillation.py)

verl 已经有 OPD 文档和能力：[On-Policy Distillation (OPD) — verl documentation](https://verl.readthedocs.io/en/latest/algo/opd.html)

研究 upstream verl OPD 如何适配到 AgentGym-RL。
